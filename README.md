# Data Analyst Academy – Unit Overview

## Description

This repository contains coursework, projects, exercises, and capstone work completed as part of the Data Analyst Academy. Throughout this unit, I developed foundational skills in data analysis, data management, data visualization, SQL, Excel, Git/GitHub, and communicating analytical findings.

The purpose of this repository is to demonstrate my ability to collect, clean, analyze, and present data-driven insights using industry-standard tools and techniques.

---

## Skills and Topics Covered

### Data Analysis Foundations

* Data analysis terminology and core concepts
* The data analysis lifecycle
* Business problem identification and analytical thinking
* Data storytelling and presentation techniques

### Data Quality and Collection

* Identifying missing or inconsistent data
* Recognizing potential sources of bias
* Evaluating data quality and reliability
* Applying best practices for data collection

### Microsoft Excel

* Data cleaning and transformation
* Lookup functions (VLOOKUP, XLOOKUP)
* Logical functions (IF, SWITCH)
* PivotTables and PivotCharts
* Data visualization and reporting

### Relational Databases

* Database design principles
* Entity Relationship Diagrams (ERDs)
* Data normalization
* Primary and foreign keys
* Data types and constraints

### SQL

* SELECT statements
* Filtering and sorting data
* Aggregate functions
* GROUP BY and HAVING clauses
* Table joins
* Subqueries
* Common Table Expressions (CTEs)
* Data analysis using SQL

### Git and GitHub

* Version control fundamentals
* Repository management
* Commit tracking
* Project documentation
* Sharing and collaboration workflows

---

## Learning Outcomes

By completing this unit, I gained the ability to:

* Apply the data analysis lifecycle to solve business problems
* Evaluate datasets for quality issues and bias
* Clean, transform, and visualize data using Excel
* Design normalized relational database schemas
* Write SQL queries to retrieve and analyze data
* Use joins, subqueries, and CTEs to answer complex questions
* Interpret analytical results and develop recommendations
* Present findings clearly to both technical and non-technical audiences
* Organize and document projects using Git and GitHub
